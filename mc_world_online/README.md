# MC World Online

This is a standalone multiplayer version of the MC World project.

## Setup
1. `cd mc_world_online`
2. `npm install`
3. `npm start`

Runs on http://localhost:3501 by default.
Uses the shared `data.db` from the root directory.

## Features
- Standalone Express server
- Socket.io for multiplayer synchronization (Prototype)
- Save/Load functionality using shared SQLite database
